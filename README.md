# SECRET WORDS — วงล้อป่วนจินตนาการ

เกมสุ่มคำภาษาไทย 3 หมวด เพื่อสร้างภาพตามจินตนาการ เปิด `index.html` หรือ `secret_words.html` บน GitHub Pages ได้โดยไม่ต้อง build

## การใช้งาน
- หมุนแยกแต่ละวง หรือหมุนพร้อมกันทั้ง 3 วง
- ตั้งค่าคำ: แก้ไขในช่องคำ กด × เพื่อลบ พิมพ์คำใหม่แล้วกดเพิ่ม หรือวางหลายคำโดยคั่นด้วยจุลภาค/บรรทัดใหม่
- โหมดเก็บคำไว้: สุ่มคำเดิมซ้ำได้
- โหมดไม่ซ้ำในรอบ: นำคำที่สุ่มได้ออกจากชุดคำที่เหลือ โดยไม่ลบคลังคำต้นฉบับ
- วงล้อค้างภาพคำที่เลือกใต้ลูกศรจนเริ่มหมุนครั้งต่อไป ส่วนจำนวนคำที่เหลืออัปเดตทันที
- เริ่มรอบใหม่: คืนคำทั้ง 3 วง และล้างผลลัพธ์
- เมื่อคำวงใดหมด ปุ่มหมุนวงนั้นและหมุนพร้อมกันจะหยุดจนเริ่มรอบใหม่ วงอื่นยังหมุนได้
- ช่วยคิดไอเดีย: แนะนำโจทย์จากคำทั้ง 3 คำโดยใช้แม่แบบภายในเกม ไม่ส่งคำออกไปบริการ AI
- การบันทึกคำหรือเปลี่ยนโหมดจะเริ่มรอบใหม่ การปิดหน้าตั้งค่าโดยไม่บันทึกจะยกเลิกการแก้ไข

คำ โหมด ผลลัพธ์ และคำที่เหลือเก็บด้วย localStorage ในเบราว์เซอร์เครื่องนี้ รองรับการนำคลังคำจากเกมเวอร์ชันเดิมมาใช้ หากบันทึกไม่ได้ เกมจะแจ้งเตือนและยังเล่นต่อได้

รองรับ 1–150 คำต่อหมวด คำละไม่เกิน 60 ตัวอักษร คำซ้ำในหมวดเดียวกันจะถูกรวม ใช้ข้อความ DOM ปลอดภัยสำหรับคำที่ผู้ใช้กรอก รองรับแป้นพิมพ์ dialog, reduced motion และหน้าจอมือถือ

## ไฟล์
- `defaults.js`: คำต้นฉบับจากเกมเดิม
- `game.js`: วงล้อ สถานะรอบ และตัวแก้คำ
- `styles.css`: หน้าตาและ responsive layout
- `assets/art-classroom.jpg`: ภาพฉากที่สร้างขึ้นสำหรับเกมตามภาพอ้างอิงของผู้ใช้

ฟอนต์ Mali โหลดจาก Google Fonts พร้อม Tahoma/sans-serif สำรองเมื่อออฟไลน์

## ตรวจสอบก่อนเผยแพร่
ทดสอบใน Chromium ทั้ง desktop และ mobile: ผลตรงกับลูกศร, หมุนแยก/พร้อมกัน, คำไม่ซ้ำจนหมด, คืนคำ, reload แล้วสถานะคงอยู่, เพิ่ม/แก้/ลบคำ, ป้องกันคลังว่าง, โหมดสุ่มซ้ำ, ไอเดีย, ล็อกการแก้ไขระหว่างหมุน และไม่มี JavaScript errors
